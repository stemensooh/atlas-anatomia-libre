# Contribuir

Este es un proyecto de aprendizaje, abierto y no comercial. Los aportes son bienvenidos si respetan estas reglas.

## Licencias
- **Código:** MIT (`LICENSE-CODE`).
- **Contenido** (modelos, textos, cuestionarios, documentación): CC BY-SA 4.0 (`LICENSE-CONTENT`).
- Al aportar, aceptas que tu código se publique bajo MIT y tu contenido bajo CC BY-SA 4.0.
- Mantén el código y el contenido en carpetas separadas.

## Reglas para recursos de terceros
1. Toda fuente nueva debe tener una fila en [docs/ATTRIBUTIONS.md](docs/ATTRIBUTIONS.md) **antes** de entrar a `data/`.
2. Verifica la licencia siguiendo [docs/ATTRIBUTION_HOWTO.md](docs/ATTRIBUTION_HOWTO.md).
3. **No se aceptan** recursos con licencia NC o ND, sin licencia explícita, ni propietarios (por ejemplo BioDigital, Visible Body o Complete Anatomy).
4. Los textos copiados de Wikipedia deben conservar la atribución (CC BY-SA 4.0).
5. Solo datasets médicos públicos y anonimizados.

## Convenciones
- Cada malla se nombra `FMA<ID>_<Nombre>_<Lado>`.
- Las descargas originales van en `data/raw/` y no se editan.
- Las decisiones técnicas se registran en [docs/DECISIONES.md](docs/DECISIONES.md).
